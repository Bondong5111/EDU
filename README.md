# 마이 플래너 · 일정 & 주식 관리

일정과 주식 포트폴리오를 한 곳에서 관리하는 개인용 웹사이트입니다. 서버나 빌드 과정 없이 `index.html`을 브라우저로 열면 바로 사용할 수 있습니다.

## 기능

- **대시보드**: 오늘 일정, 앞으로 7일 일정, 포트폴리오 요약과 종목 비중 도넛 차트
- **일정**: 월간 달력, 일정 추가/수정/삭제, 시간·분류(업무/개인/투자·금융/기타)·메모, 완료 체크
- **주식**
  - 매수/매도 기록 → 보유 수량·평균단가 자동 계산 (이동평균법)
  - 현재가 입력 → 평가금액, 평가손익, 수익률, 실현손익
  - 목표가 설정 및 "목표 도달" 표시
  - 관심 종목 목록
- **설정**: 원/달러 표시, JSON 백업 내보내기/가져오기, 초기화

## 실행

```bash
# 그냥 파일을 열어도 되고
open index.html
# 로컬 서버로 띄우려면
python3 -m http.server 8000   # → http://localhost:8000
```

GitHub Pages로 배포하면 휴대폰에서도 접속할 수 있습니다 (Settings → Pages → 브랜치 선택).

## 데이터 저장

모든 데이터는 브라우저의 `localStorage`에 저장됩니다. 다른 브라우저·기기로 옮기려면 설정 탭에서 백업 파일을 내보내고 가져오세요. 현재가는 직접 입력하는 방식입니다(실시간 시세 API 미연동).
