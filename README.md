# MY LIFE · 나를 관리하는 플랫폼

나에 대한 소개·강점·사주부터 습관·컨디션·목표 같은 자기관리, 그리고 일정과 주식까지 한 곳에서 관리하는 개인용 웹사이트입니다.
휴대폰과 PC에서 같은 데이터를 쓰려면 통합 서버로 실행하고, 간단히 써보려면 `index.html`을 브라우저로 열면 됩니다.

## 화면 구성

기록을 쌓고(입력), 다시 보고(열람), 이해하는(분석) 흐름으로 나뉘어 있습니다.

| 탭 | 역할 |
|---|---|
| **홈** | 요약 허브. 오늘 달성 링과 한 번 탭 기분 기록, 핵심 지표 4개(7일·30일·1년 평균과 추세), 1년 히트맵, 발견, 목표, 자산 추이, 예전 오늘 다시 보기 |
| **기록** | 보관함. 달력(기분·일정 표시), 날짜별 하루 카드, 일기·일정 검색, 지난 기록 타임라인, CSV 내보내기 |
| **분석** | 지표별 추세(기분·수면·걸음·체중·섭취 칼로리 등, 30일·90일·1년), 요일별 패턴, 발견(함께 나타나는 경향), 습관 달성률, 주간 리뷰 |
| **자산** | 포트폴리오, 날짜별로 쌓인 자산 추이, 종목 비중, 매매 기록, 관심 종목 |
| **나** | 프로필·강점·사주와 데이터로 본 나, 목표·습관 관리, 연동·백업 설정 |

어느 화면에서든 **기록하기** 버튼으로 빠른 기록 창을 엽니다. 기분은 한 번 누르면 저장되고, 수면·운동·일기 등은 선택입니다.

### 기록이 쌓이는 방식

- 모든 기록은 **한 건이 한 줄**입니다. 예: 그날의 기분, 수면 시간, 습관 체크 한 번, 일정 한 건, 그날의 자산 평가금액.
- 서버는 SQLite 데이터베이스(`server/data/mylife.db`)에 줄 단위로 저장하고, 기기와는 **바뀐 줄만** 주고받습니다. 두 기기가 서로 다른 줄을 고치면 충돌 없이 합쳐지고, 같은 줄을 고치면 나중에 저장한 쪽이 남습니다.
- 삭제는 줄을 지우지 않고 삭제 표시를 남겨 다른 기기에도 전달합니다.
- 목표를 습관에 연결하면 진행률이 체크 횟수로 자동 계산됩니다.
- 발견은 기분 기록이 14일 이상 쌓이면 나타납니다. 인과가 아닌 경향입니다.

## 한 곳에서 모두 연결: 통합 서버

`server/server.mjs` 하나를 실행하면 웹사이트·로그인·데이터 동기화·토스증권·구글 캘린더·팻시크릿이 모두 연결됩니다. Node.js 22.13 이상이 필요합니다(내장 SQLite 사용, 따로 설치할 것 없음).

```bash
cp server/.env.example server/.env    # 비밀번호 등 입력
npm start
```

| 기능 | 설명 |
|---|---|
| 동기화 | 휴대폰·PC 어디서든 같은 데이터. 오프라인일 땐 기기에 보관했다가 연결되면 저장 |
| 토스증권 | 보유 주식·평가손익·환율. 자산/홈 화면을 열 때 10분이 지났으면 자동 갱신 |
| 구글 캘린더 | 한 번 연결하면 유지. 기록/홈 화면을 열 때 15분이 지났으면 자동 가져오기, 새 일정을 구글에도 추가 |
| 팻시크릿 | 기존 계정을 한 번 연결하면 유지. 식단(섭취 칼로리·탄단지)과 체중을 날짜별 기록으로 가져오고, 화면을 열 때 1시간이 지났으면 자동 갱신 |
| 삼성헬스 | 공개 API가 없어 앱의 개인 데이터 다운로드 CSV를 올리는 방식 (수면·걸음 수·운동·체중) |
| 앱 설치 | 휴대폰 홈 화면에 추가하면 앱처럼 실행 (오프라인에서도 화면 열림) |

홈 화면 아래에서 다섯 가지 연결 상태를 볼 수 있고, 나 → **연동 · 설정**에서 연결·해제합니다.
자세한 설치·배포 방법: **[server/README.md](server/README.md)**

서버 없이 `index.html`만 열어도 동작하며, 이때는 이 기기에만 저장되고 토스·구글·팻시크릿 연동은 꺼집니다.

### 삼성헬스 가져오기

삼성헬스 앱 → 설정 → 개인 데이터 다운로드 → 받은 폴더에서 아래 파일을 나 → 연동 · 설정의 **CSV 선택**으로 함께 올리세요.

- `com.samsung.shealth.sleep.*.csv` → 수면 (깬 날짜 기준 합계)
- `com.samsung.shealth.tracker.pedometer_day_summary.*.csv` → 걸음 수
- `com.samsung.shealth.exercise.*.csv` → 운동 시간
- `com.samsung.health.weight.*.csv` → 체중

반영 전에 인식한 항목과 일수를 보여주고 확인을 받습니다. 기분·일기 등 직접 쓴 기록은 유지됩니다.

## 사주 계산 (`js/saju.js`)

- 태양 황경을 직접 계산해 **절기 기준**으로 연주(입춘)와 월주를 정합니다.
- 일주는 1900-01-01 = 甲戌일을 기준으로, 시주는 일간 기준 오자둔으로 계산합니다.
- 입력 시각은 한국 표준시로 간주합니다. 서머타임과 진태양시 보정은 하지 않으며, 자시(子時)는 자정을 기준으로 날짜를 나눕니다.
- 절기 경계 근처에서 태어났으면 화면에 안내가 표시됩니다.
- 재미와 참고용입니다.

## 데이터 저장

- 통합 서버: `server/data/mylife.db`(SQLite)에 기록 단위로 저장하고 1시간마다 `server/data/backups/`에 백업. 각 기기에는 오프라인용 사본만 남음 (로그아웃 시 삭제)
- 서버 없이: 브라우저 `localStorage`에만 저장
- 내보내기: 기록 탭의 CSV(날짜별 한 줄), 나 → 연동 · 설정의 전체 JSON
