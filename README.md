# MY LIFE · 나를 관리하는 플랫폼

나에 대한 소개·강점·사주부터 습관·컨디션·목표 같은 자기관리, 그리고 일정과 주식까지 한 곳에서 관리하는 개인용 웹사이트입니다.
휴대폰과 PC에서 같은 데이터를 쓰려면 통합 서버로 실행하고, 간단히 써보려면 `index.html`을 브라우저로 열면 됩니다.

## 화면 구성

| 탭 | 내용 |
|---|---|
| **홈** | 프로필 카드, 오늘의 습관 체크, 오늘/다가오는 일정, 최근 7일 컨디션, 목표 진행률, 포트폴리오 요약 |
| **나** | 프로필(이름·한 줄 소개·자기소개·MBTI·좌우명·관심사·5년 후 비전), 강점과 보완점, 사주 원국과 오행 분포 |
| **자기관리** | 습관 트래커(7일 체크, 연속 일수 🔥), 일일 기록(기분·에너지·수면·운동·체중·감사·회고), 14일 컨디션 그래프, 목표(분야·기한·D-day·진행률) |
| **일정** | 월간 달력, 일정 추가·수정·삭제, 분류·완료 체크 |
| **주식** | 매수/매도 기록으로 보유 수량과 평균단가 자동 계산, 평가/실현 손익, 목표가 알림, 관심 종목 |
| **설정** | 원/달러 표시, 연동 현황(연결·해제·로그아웃), JSON 백업 내보내기·가져오기, 초기화 |

## 한 곳에서 모두 연결: 통합 서버

`server/server.mjs` 하나를 실행하면 웹사이트·로그인·데이터 동기화·토스증권·구글 캘린더가 모두 연결됩니다.

```bash
cp server/.env.example server/.env    # 비밀번호 등 입력
node --env-file=server/.env server/server.mjs
```

| 기능 | 설명 |
|---|---|
| ☁️ 동기화 | 휴대폰·PC 어디서든 같은 데이터. 동시에 바꿔도 항목 단위로 자동 병합, 오프라인일 땐 기기에 보관했다가 연결되면 저장 |
| 📈 토스증권 | 보유 주식·평가손익·환율. 주식/홈 화면을 열 때 10분이 지났으면 자동 갱신 |
| 📅 구글 캘린더 | 한 번 연결하면 유지. 일정/홈 화면을 열 때 15분이 지났으면 자동 가져오기, 새 일정을 구글에도 추가 |
| ❤️ 삼성헬스 | 공개 API가 없어 앱의 개인 데이터 다운로드 CSV를 올리는 방식 (수면·걸음 수·운동·체중) |
| 📱 앱 설치 | 휴대폰 홈 화면에 추가하면 앱처럼 실행 (오프라인에서도 화면 열림) |

홈 화면 상단에서 네 가지 연결 상태를 한눈에 볼 수 있고, 설정 → **연동 현황**에서 연결·해제합니다.
자세한 설치·배포 방법: **[server/README.md](server/README.md)**

서버 없이 `index.html`만 열어도 동작하며, 이때는 이 기기에만 저장되고 토스·구글 연동은 꺼집니다.

### 삼성헬스 가져오기

삼성헬스 앱 → 설정 → 개인 데이터 다운로드 → 받은 폴더에서 아래 파일을 자기관리 탭의 **CSV 선택**으로 함께 올리세요.

- `com.samsung.shealth.sleep.*.csv` → 수면 (깬 날짜 기준 합계)
- `com.samsung.shealth.tracker.pedometer_day_summary.*.csv` → 걸음 수
- `com.samsung.shealth.exercise.*.csv` → 운동 시간
- `com.samsung.health.weight.*.csv` → 체중

반영 전에 인식한 항목과 일수를 보여주고 확인을 받습니다. 기분·일기 등 직접 쓴 기록은 유지됩니다.

## 사주 계산 (`js/saju.js`)

- 태양 황경을 직접 계산해 **절기 기준**으로 연주(입춘)와 월주를 정합니다.
- 일주는 1900-01-01 = 甲戌일을 기준으로, 시주는 일간 기준 오자둔으로 계산합니다.
- 입력 시각은 한국 표준시로 간주합니다. 서머타임과 진태양시 보정은 하지 않으며, 자시(子時)는 자정을 기준으로 날짜를 나눕니다.
- 절기 경계 근처에서 태어났으면 화면에 안내가 표시됩니다.
- 재미와 참고용입니다.

## 데이터 저장

- 통합 서버: 서버의 `server/data/db.json`에 저장되고 1시간마다 백업. 각 기기에는 오프라인용 사본만 남음 (로그아웃 시 삭제)
- 서버 없이: 브라우저 `localStorage`에만 저장. 설정 탭에서 JSON으로 내보내기·가져오기
