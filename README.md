# MY LIFE · 나를 관리하는 플랫폼

나에 대한 소개·강점·사주부터 습관·컨디션·목표 같은 자기관리, 그리고 일정과 주식까지 한 곳에서 관리하는 개인용 웹사이트입니다.
서버나 빌드 과정 없이 `index.html`을 브라우저로 열면 바로 사용할 수 있습니다.

## 화면 구성

| 탭 | 내용 |
|---|---|
| **홈** | 프로필 카드, 오늘의 습관 체크, 오늘/다가오는 일정, 최근 7일 컨디션, 목표 진행률, 포트폴리오 요약 |
| **나** | 프로필(이름·한 줄 소개·자기소개·MBTI·좌우명·관심사·5년 후 비전), 강점과 보완점, 사주 원국과 오행 분포 |
| **자기관리** | 습관 트래커(7일 체크, 연속 일수 🔥), 일일 기록(기분·에너지·수면·운동·체중·감사·회고), 14일 컨디션 그래프, 목표(분야·기한·D-day·진행률) |
| **일정** | 월간 달력, 일정 추가·수정·삭제, 분류·완료 체크 |
| **주식** | 매수/매도 기록으로 보유 수량과 평균단가 자동 계산, 평가/실현 손익, 목표가 알림, 관심 종목 |
| **설정** | 원/달러 표시, 토스·구글 연동 설정, JSON 백업 내보내기·가져오기, 초기화 |

## 외부 연동

| 연동 | 방식 | 준비할 것 |
|---|---|---|
| **토스증권** | 조회 전용 중계 서버(`server/toss-proxy.mjs`)를 거쳐 보유 주식·평가손익·환율을 불러옴. 주식 탭을 열 때 10분이 지났으면 자동 갱신 | 고정 IP 컴퓨터, 토스증권 Open API 키 → [server/README.md](server/README.md) |
| **구글 캘린더** | 브라우저에서 구글 로그인(OAuth) 후 일정 가져오기, 새 일정을 구글에도 추가 | Google Cloud OAuth 클라이언트 ID (아래) |
| **삼성헬스** | 앱의 개인 데이터 다운로드 CSV를 올리면 수면·걸음 수·운동·체중을 날짜별 기록에 반영 | 휴대폰에서 데이터 내보내기 |

### 구글 캘린더 설정

1. [Google Cloud 콘솔](https://console.cloud.google.com/)에서 프로젝트 생성 → **Google Calendar API** 사용 설정
2. OAuth 동의 화면: 사용자 유형 *외부*, 테스트 사용자에 본인 구글 계정 추가
3. 사용자 인증 정보 → **OAuth 클라이언트 ID** → 웹 애플리케이션
   - 승인된 자바스크립트 원본: `https://<GitHub아이디>.github.io`
4. 발급된 클라이언트 ID를 웹사이트 **설정 → 연동**에 입력 → 일정 탭에서 **연결**

로그인 토큰은 브라우저 탭을 닫으면 사라집니다(1시간 유효). 구글에서 가져온 일정은 사이트에서 수정할 수 없고 ↗ 버튼으로 구글 캘린더에서 엽니다.

### 삼성헬스 가져오기

삼성헬스 앱 → 설정 → 개인 데이터 다운로드 → 받은 폴더에서 아래 파일을 자기관리 탭의 **CSV 선택**으로 함께 올리세요.

- `com.samsung.shealth.sleep.*.csv` → 수면 (깬 날짜 기준 합계)
- `com.samsung.shealth.tracker.pedometer_day_summary.*.csv` → 걸음 수
- `com.samsung.shealth.exercise.*.csv` → 운동 시간
- `com.samsung.health.weight.*.csv` → 체중

반영 전에 인식한 항목과 일수를 보여주고 확인을 받습니다. 기분·일기 등 직접 쓴 기록은 유지됩니다.

### 보안 메모

- 토스 `PROXY_TOKEN`은 이 브라우저에만 저장되며 백업(JSON) 파일에 포함되지 않습니다.
- 토스 `client_secret`은 중계 서버 환경변수에만 둡니다. 웹사이트·GitHub에 넣지 마세요.

## 배포 (GitHub Pages)

`main` 브랜치에 올리면 `.github/workflows/pages.yml`이 웹사이트 파일만 골라 배포합니다.
처음 한 번 저장소 **Settings → Pages → Source**를 *GitHub Actions*로 바꿔 주세요.
주소: `https://<GitHub아이디>.github.io/<저장소이름>/`

## 사주 계산 (`js/saju.js`)

- 태양 황경을 직접 계산해 **절기 기준**으로 연주(입춘)와 월주를 정합니다.
- 일주는 1900-01-01 = 甲戌일을 기준으로, 시주는 일간 기준 오자둔으로 계산합니다.
- 입력 시각은 한국 표준시로 간주합니다. 서머타임과 진태양시 보정은 하지 않으며, 자시(子時)는 자정을 기준으로 날짜를 나눕니다.
- 절기 경계 근처에서 태어났으면 화면에 안내가 표시됩니다.
- 재미와 참고용입니다.

## 실행

```bash
python3 -m http.server 8000   # → http://localhost:8000
```

또는 `index.html`을 더블클릭해서 열어도 됩니다. GitHub Pages로 배포하면 휴대폰에서도 쓸 수 있습니다.

## 데이터 저장

모든 데이터는 브라우저의 `localStorage`에만 저장되고 외부로 전송되지 않습니다. 다른 기기로 옮기려면 설정 탭에서 백업 파일을 내보내고 가져오세요.
